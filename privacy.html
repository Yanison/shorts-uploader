개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-11-22

1. 요청하는 권한 / Requested permissions

  • youtube.upload — 운영자 채널에 영상 업로드 / Upload videos to the operator's channel
  • youtube.readonly — 채널 정보 읽기(업로드 대상 확인) / Read channel information to confirm the upload target

2. 수집·저장하는 정보 / Data collected and stored

OAuth 토큰만 운영자의 로컬 환경에 저장하며, 그 외의 개인정보는 수집하지 않습니다.
Only OAuth tokens are stored, in the operator's local environment. No other personal information is collected.

3. 제3자 제공 및 이용 목적 / Sharing and use

수집한 정보는 제3자에게 제공하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.
Data is not shared with third parties and is not used for advertising or analytics.

4. Google API 정책 준수 / Google API compliance

본 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
IT News Shorts Uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 권한 철회 / Revoking access

Google 계정 > 보안 > 서드파티 앱 액세스에서 언제든 접근 권한을 해제할 수 있습니다.
You can revoke access at any time in Google Account > Security > Third-party apps with account access (myaccount.google.com/permissions).

6. 연락처 / Contact

OAuth 동의 화면에 등록된 운영자 이메일로 문의해 주세요. / Please contact the operator via the email listed on the OAuth consent screen.
